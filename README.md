# 🎬 CINEMAX — Movie-Streaming Homepage

A modern, responsive movie-streaming web application inspired by platforms like Netflix, built with semantic **HTML5**, **CSS3 (Flexbox & Grid)**, and modern **Vanilla JavaScript**.

---

## 🌟 Key Features

1. **🧭 Glassmorphic Navigation Bar**:
   - Brand logo with glow effect.
   - Smooth navigation links (`Home`, `Movies`, `TV Shows`, `Genres`, `My List`).
   - Dynamic real-time search input with clear button.
   - Notification bell with counter badge.
   - Profile avatar with interactive dropdown (`Prathmesh`, `Account`, `Watchlist`, `Sign Out`).
   - Transparent to blurred frosted-glass transition when scrolling.

2. **🎞️ Hero / Featured Blockbuster**:
   - Showcases **The Dark Knight** with a cinematic backdrop and vignette gradients.
   - Metadata badges: Rating (⭐ 9.0), release year, duration, 4K Ultra HD & 5.1 Surround sound tags.
   - Interactive CTA buttons: `▶ Play Now`, `+ My List`, and `ℹ More Info`.

3. **🎬 Categorized Movie Carousels**:
   - 🔥 **Trending Now**: *Oppenheimer, Dune: Part Two, Barbie, Avatar: The Way of Water, Joker*
   - ⭐ **Popular on Cinemax**: *The Dark Knight, Inception, Interstellar, The Matrix, Titanic*
   - 💥 **Action & Thrillers**: *John Wick: Chapter 4, Avengers: Endgame, Top Gun: Maverick, Mad Max: Fury Road*
   - 😂 **Comedy & Adventure**: *Deadpool, Free Guy, The Hangover, Superbad, Jumanji*
   - Smooth horizontal scrolling with left/right carousel arrows (`[ < ]` and `[ > ]`).

4. **🖱️ Card Hover Effects & Micro-Interactions**:
   - Card scale (`1.05`) and elevation (`translateY(-8px)`) with glowing red borders.
   - Poster zoom and darkened overlay revealing the play button `▶`.
   - Quick `+` watchlist toggle button on every card.

5. **🔍 Real-Time Live Search**:
   - Instant search through titles, genres, and cast members.
   - Dedicated search results grid displaying the match count dynamically.

6. **❤️ "My List" Watchlist Management**:
   - Add or remove any movie with one click.
   - Syncs with `localStorage` so choices persist across browser refreshes.
   - Dynamic counter badge and interactive toast notifications.

7. **📽️ Rich Movie Details Modal**:
   - High-resolution movie backdrop, synopsis, cast members, runtime, and streaming tags.
   - Accessible via keyboard (<kbd>Esc</kbd>) or backdrop click.

8. **📱 Mobile & Desktop Responsive**:
   - Fluid responsiveness across desktop monitors, laptops, tablets, and mobile smartphones.
